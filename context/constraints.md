# Constraints — What NOT to do

## Never
- Add a backend, database, or cloud service
- Add authentication or user accounts
- Add analytics or telemetry
- Break the single-file constraint
- Use Tailwind, styled-components, or any CSS library
- Use emoji in the primary interface
- Use cartoon mascots
- Add confetti, coin sounds, or slot-machine rewards
- Change the palette to yellow/black hazard stripes
- Include text on any hero image
- Invent facts not present in the source materials

## Always
- Cite the source on every card (file + page)
- Provide the physical reason, not just the correct answer
- Respect prefers-reduced-motion
- Provide keyboard equivalents for every drag interaction
- Test that the file runs by double-clicking it (no server required)
- Write generated files to output/
- Append a summary to memory/build_log.md when a task is complete

## When unsure
Ask me. Do not invent a value, a procedure, or a hazard.
