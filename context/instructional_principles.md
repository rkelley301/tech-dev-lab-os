# Instructional Principles

These are non-negotiable. Every tool, card, and explanation must honor them.

## 1. Decision before definition
Never show a formula or rule without first presenting a symptom that
forces the user to make a choice. The user acts, fails or succeeds, and
then receives the explanation.

## 2. Split-half thinking is the spine
Every tool should reinforce the same mental model: measure in the middle
of what is left. A reading that eliminates nothing was the wrong reading.

## 3. Productive failure is a feature
Wrong answers are not punished. They trigger a consequence — a simulated
fault cascades, a process trips, a transmitter is needlessly replaced.
The user then rewinds and retries. Failure is the teaching mechanism.

## 4. The evidence trail is the deliverable
Every tool should produce something the user can take away: a filled
triage card, a split-half log, an as-found record. The artifact is the
skill.

## 5. Spaced recall without friction
The same pattern reappears in a new disguise a few cards later. Same rule,
different symptom. The user feels familiarity before they realize they
are being taught.

## 6. Every number is earned
No textbook values. Every mA reading, mV drop, or psi corresponds to a
real field scenario from the source material. No filler.

## 7. Cite the source
Every card cites its source file and page number.
