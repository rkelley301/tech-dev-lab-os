# Project Brief — Tech Dev Lab

## What it is
An interactive single-file HTML training tool for instrumentation & controls
technicians. The tool is not a course. It is a diagnostic simulator.

## The pedagogical thesis
The market is full of courses that teach what a transmitter is. Almost none
teach what to do when the transmitter is wrong. Tech Dev Lab is built on
one principle: the user must make a decision before they receive an
explanation.

## The five layers of the tool
1. Electrical Controls — 24 VDC circuits, relays, NO/NC logic, sourcing/sinking
2. Instrumentation — 2/3/4-wire devices, scaling, RTDs, transmitters, calibration
3. PLC Troubleshooting — I/O maps, permissives, timers, symptom diagnosis
4. Programming — ladder edits, HMI tag bind, change control
5. Drill (planned) — randomized fundamental drills on rotation

## Terminal outcome for the user
By the end, a user can take an unfamiliar instrument fault, isolate it to
field device / wiring / power / controller in a documented measurement
sequence, and prove the fix with a loop check.

## Target user
New E&I technicians (0–2 years), electricians transitioning into
instrumentation, apprentices preparing for plant troubleshooting evaluations.
They are technically capable but have not yet developed diagnostic judgment.
